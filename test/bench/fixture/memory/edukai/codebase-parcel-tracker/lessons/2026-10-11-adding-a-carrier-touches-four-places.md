A new carrier has to be added in four places: the carrier list in the registry, the webhook map, the tracking-number normaliser, and `snapshots/carriers.snap.json`. The snapshot is generated by `npm run snapshot`; a hand-edited one fails its checksum test. Run the generator last, after the other three.[^snapshot]

[^snapshot]: The generator script writes the snapshot from the registry, the webhook map and the normaliser.
